# Deep Learning & AI Portfolio

This repository contains a collection of Deep Learning models developed as part of my Advanced AI studies.

### 🧠 Models Included:

1. **CNN1**: Image classification using Convolutional Neural Networks.
2. **ANN1 & ANN2CIFAR**: Artificial Neural Networks for tabular and image data.
3. **Autoencoders (Simple & Convolutional)**: Neural networks for data compression and feature learning.
4. **Titanic Classification**: Classic machine learning classification problem.
5. **Regression Dataset**: Predicting continuous values using deep learning.

### 🛠 Tech Stack

* **Frameworks:** TensorFlow, Keras
* **Environment:** Google Colab / Jupyter Notebooks
