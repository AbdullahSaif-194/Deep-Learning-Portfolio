# Deep Learning & AI Portfolio

This repository contains a collection of Deep Learning models and Generative AI systems developed as part of my Advanced AI studies.

### 🤖 Featured AI Projects:

1. **Advanced RAG System (ai_practice.py)**: A Retrieval-Augmented Generation pipeline built with LangChain, HuggingFace embeddings, and the Qdrant vector database to chat with custom PDF documents.
2. **CNN1**: Image classification using Convolutional Neural Networks.
3. **ANN1 & ANN2CIFAR**: Artificial Neural Networks designed for pattern recognition in both tabular and image (CIFAR-10) datasets.
4. **Autoencoders (Simple & Convolutional)**: Neural networks implemented for data compression, denoising, and feature learning.
5. **Titanic Classification**: A classic machine learning implementation solving the survival prediction problem.
6. **Regression Analysis**: Deep learning models for predicting continuous numerical values.

### 🛠 Tech Stack

* **AI Frameworks:** TensorFlow, Keras, LangChain, HuggingFace
* **Vector Database:** Qdrant
* **Environment:** Python (Local Venv), Jupyter Notebooks, Google Colab
